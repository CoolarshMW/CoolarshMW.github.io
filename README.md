# harshwangikar.github.io

Personal portfolio of **Harsh Wangikar**, Business & Data Analyst.

Built with [Astro](https://astro.build) and TypeScript, deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Update the content

All text, projects, skills and the timeline live in `src/data/profile.ts`. Edit that file and push; the site rebuilds in about a minute.

## Run locally

```
npm install
npm run dev
```
